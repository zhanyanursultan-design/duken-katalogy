# SmartStore Robot AI

Дүкендегі робот мысалында екі машиналық оқыту тәсілін көрсететін интерактивті оқу сайты.

1. Reinforcement Learning
Робот тауарды сөреге орналастырады. Дұрыс әрекет +10 сыйақы, қате әрекет -5 жаза. Auto Train режимі тәжірибені бірнеше рет қайталайды.

2. Semi-Supervised Learning
100 белгіленген және 900 белгіленбеген тауар мысалы арқылы жартылай оқыту принципі көрсетіледі. AI белгіленбеген тауарларға pseudo-label ұсынады.

GitHub Pages үшін index.html, style.css, app.js файлдарын репозиторий түбіріне жүктеңіз.
