# SmartStore AI

Интерактивті оқу жобасы: дүкен тауарларын классификациялау және кластеризациялау.

## Мүмкіндіктер
- Тауарлар каталогы
- KNN классификациясы
- K-Means кластеризациясы
- Интерактивті Chart.js диаграммалары
- Жаңа тауар қосу
- Адаптивті дизайн

## GitHub Pages
1. Репозиторийге `index.html`, `style.css`, `app.js` файлдарын жүктеңіз.
2. Settings → Pages бөліміне кіріңіз.
3. Deploy from a branch → `main` → `/root` таңдаңыз.
4. Save басыңыз.

Ескерту: Chart.js және Google Fonts CDN арқылы жүктеледі, сондықтан диаграммалар мен веб-қаріп үшін интернет қажет.
